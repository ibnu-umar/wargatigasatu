# 🌐 Warga Tiga Satu (RT 03 / RW 01 Kramas)

Portal informasi resmi, kegiatan, dan pelayanan publik masyarakat **RT 03 / RW 01 Kelurahan Kramas**.

---

## 📌 Tentang Website

Website ini dibuat untuk memudahkan warga dalam mengakses informasi terkini seputar lingkungan RT 03 / RW 01 Kramas, seperti pengumuman resmi, agenda kegiatan, galeri dokumentasi, hingga sarana kontak pengurus RT.

---

## ✨ Fitur & Halaman

- **Beranda (`index.html`)**: Halaman utama dengan sambutan, ringkasan pengumuman, agenda terdekat, dan berita terbaru.
- **Profil (`profil.html`)**: Informasi struktur kepengurusan RT, visi & misi, serta gambaran umum wilayah.
- **Kegiatan Warga (`kegiatan-warga.html`)**: Jadwal dan dokumentasi kegiatan warga (gotong royong, senam, pengajian, posyandu, dll).
- **Informasi (`informasi.html`)**: Pusat edaran resmi, pengumuman penting, dan tata tertib lingkungan.
- **Berita (`berita.html`)**: Arsip artikel dan liputan kegiatan seputar warga.
- **Galeri (`galeri.html`)**: Dokumentasi foto kegiatan dan momen kebersamaan warga.
- **Kontak (`kontak.html`)**: Informasi kontak pengurus RT, layanan aduan, dan form pesan/aspirasi warga.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5** – Struktur halaman semantik.
- **CSS3** – Desain responsif, animasi halus, dan tata letak modern.
- **JavaScript (Vanilla)** – Interaktivitas navbar, filter, dan komponen dinamis.
- **Font Awesome 6** – Ikon visual.

## 🚀 Cara Menjalankan

1. **Clone repository:**
   ```bash
   git clone https://github.com/ibnu-umar/wargatigasatu.git
   ```
2. **Buka folder proyek:**
   ```bash
   cd wargatigasatu
   ```
3. **Jalankan:**
   - Cukup buka file `index.html` langsung di browser pilihan Anda, atau
   - Gunakan extension **Live Server** di VS Code untuk pengalaman yang lebih optimal.
